Today we're introducing [Flow](/plugins/official/flow/), a SpecDD plugin that helps coding agents tackle complex changes
more efficiently and reliably.

An agent tackling a large feature has to track decisions, dependencies, and unfinished tasks as the conversation grows.
Flow gives it a temporary working plan and a repeatable process for delegating focused tasks, reviewing results, and
moving through the work.

Your main agent coordinates independent work in parallel where safe and checks how the changes fit together. You review
the plan before implementation and can step in to question assumptions, pause, or redirect the work along the way.

The aim is less repeated planning and avoidable rework, with clearer opportunities for you to steer a complex feature
through completion.

Read the [Flow guide](/plugins/official/flow/) to learn more and try it in your project.
